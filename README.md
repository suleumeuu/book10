# C++ машинаға бағытталған бағдарламалау — электрондық оқулық

Сайт GitHub Pages үшін дайындалған. Интерфейс PDF оқырманы сияқты жасалған: жоғарғы басқару панелі, беттерді ауыстыру, бет нөмірі, масштаб, толық экран және мазмұн бойынша тікелей бетке өту.

## Жариялау
1. ZIP архивін жүктеп, толық шығарып алыңыз.
2. Репозиторийдің түбіріне ішіндегі барлық файлдар мен бумаларды жүктеңіз. `index.html` түбірде қалуы керек.
3. GitHub-та `Settings → Pages → Deploy from a branch` таңдаңыз.
4. `main` тармағын және `/(root)` бумасын таңдап, сақтаңыз.

Негізгі оқулық `assets/book.pdf` ішінде. Мазмұндағы әр тақырып нөмірленген бетке апарады. Бастапқы DOCX құжаттары `source-files/` ішінде сақталған.
